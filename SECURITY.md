# Security Policy

## Supported versions

bundlemcp is a pre-1.0 preview. Security fixes land in a new release on the newest minor line only; upgrade to it to
receive them.

| Version | Supported |
| ------- | --------- |
| 0.4.x   | yes       |
| < 0.4   | no        |

## Reporting a vulnerability

**Do not open a public issue, discussion or pull request for a security problem.**

Report it privately through GitHub's private vulnerability reporting:

https://github.com/wingfold-ai/bundlemcp/security/advisories/new

Include what you can of the following:

- the affected version or commit
- how to reproduce the problem, or a proof of concept
- the impact you expect an attacker could achieve

## What to expect

- We acknowledge a report within 3 working days, and always within 14 days.
- We tell you whether we can reproduce the problem and what we plan to do.
- We aim to release a fix within 90 days and coordinate the publication date with you.
- We publish a GitHub Security Advisory for confirmed vulnerabilities and credit the reporter unless you ask us not to.
